# Publication assets

`taiga-port.png` is the project cover selected on 2026-10-15: the supplied square TAIGA logo with a small, centered lowercase `port` line beneath the main lettering. Use it for the CurseForge project logo and repository presentation.

The cover was edited with the built-in `image_gen` tool. The exact prompt is retained in [cover-prompt.txt](cover-prompt.txt), and the user-supplied 64×64 reference is retained in [../art/source/taiga-cover-reference.png](../art/source/taiga-cover-reference.png). The original TAIGA artwork is credited to the upstream project and contributors; this derived cover is distributed with this project's GPL-3.0-only license and original notices.

The selected output is an opaque RGB PNG, 1254×1254 pixels. CurseForge's [project submission guide](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips) accepts square PNG logos of at least 400×400 pixels and downscales larger images during submission.

An additional **16:10 landscape cover**, `taiga-port-16x10.png` (1920×1200), was created on 2026-10-17 with the built-in image tool using the square cover as its edit target. Its exact prompt is in [cover-16x10-prompt.txt](cover-16x10-prompt.txt), and the unmodified 1586×992 generated output is retained as `art/source/taiga-cover-16x10-generated.png`. For the exact requested export ratio, one pixel was removed from each edge to obtain 1584×990, then the image was uniformly exported to 1920×1200 with bicubic sampling. The wordmark proportions are preserved. The landscape cover is an additional promotional asset; the square project logo is retained.

[description-zh_cn.md](description-zh_cn.md) is the complete Simplified Chinese project introduction, including features, armor behavior by version, dependency baselines, trait configuration, upstream credits and license. It is supplied for Chinese-language project pages and posts.

`curseforge-project.json` records the project metadata, including the logo path, enabled comments and allowed third-party distribution. `curseforge-description.md` contains the English project description.

The project was created through the in-app browser on 2026-10-15 as **1744942**, with the slug `taiga-tconstruct3-port`. The new cover, enabled comments, GPLv3 license, third-party distribution and GitHub source URL were saved in the author dashboard. Tinkers Construct and Mantle were also saved as default required dependencies. All three Beta files were submitted with automatic publication after approval. `curseforge-release.json` records their file IDs and local SHA-256 hashes. Project and file approval were still pending at submission; the dashboard's current state is authoritative.
